# GRAND AMORE — сайт с предложением

Одностраничный сайт с коммерческим предложением для вокальной группы GRAND AMORE (Петрозаводск):
шоурил, фото с выступлений, анализ, позиционирование, 10 идей для КП и план работы.

## Как открыть
Откройте `index.html` в браузере. Сборка не нужна: это обычный HTML, стили внутри файла, шрифты загружаются с Google Fonts.

## Структура
- `index.html` — страница
- `media/` — шоурил (`showreel.mp4`), постер к видео, фото и монограмма GA
